# FirstAlphabet 🎓

An online education platform for **Classes 8–12 (Arts)** supporting  
**West Bengal Board** and **Jharkhand Board**.  
More boards can be added in the future.

---

## 📘 Project Overview

**FirstAlphabet** is a role-based educational platform designed for schools and students.  
It provides chapter-wise learning, MCQ practice, online tests, and previous year question papers with secure access.

The platform has separate panels for:
- Super Admin
- Admin
- Teacher
- Student

---

## 🧩 Key Features

### 📚 Learning & Exams
- Chapter-wise MCQs
- Practice MCQ sessions
- Chapter-wise tests
- Previous year question papers
- Automatic test records & performance tracking

### 🔐 Security
- Copy–paste disabled for students and teachers (view-only mode)
- Role-based access control

---

## 👥 User Panels

### 👑 Super Admin Panel
- Create and manage Admins
- Assign specific permissions
- Full system access

---

### 🛠️ Admin Panel
- Manage boards, classes, subjects
- Manage teachers and students
- Upload MCQs and question papers
- View reports and records

---

### 👨‍🏫 Teacher Panel

**Teacher Details**
- School Name
- Name
- Subject (access only assigned subject)
- Phone Number
- Email

**Teacher Permissions**
- Add MCQs
- Add short answer questions
- Add descriptive questions
- Create chapter-wise tests
- View student performance

---

### 🎓 Student Panel

**Student Details**
- Board Name
- Name
- Class
- Roll Number
- Mobile Number
- Email
- School Name
- Head of Institute Name

**Student Permissions**
- Practice chapter-wise MCQs
- Take chapter-wise tests
- View test history
- Access previous year question papers

---

## 📝 Question Types
